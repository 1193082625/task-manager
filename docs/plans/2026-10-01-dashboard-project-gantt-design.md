# Dashboard 进行中项目任务甘特图

## 目标

在 Dashboard 的指标卡下方增加“进行中项目 · 任务排期”区块，让用户快速查看一个进行中项目在近期两周内的任务安排。

## 数据范围

- 项目选择框只展示状态为 `doing` 的项目，默认选中列表中的第一个项目。
- 时间窗口固定为今天前 7 天至今天后 6 天，共 14 天。
- 展示所选项目中计划时间与该窗口有交集的任务；不按任务状态过滤。
- 任务条的位置和长度由 `startTime`、`endTime` 计算。跨出窗口的任务在对应边界截断。

## 界面与交互

- 表头按天显示星期和日期；今天以强调色标识，并在内容区绘制一条竖向参考线。
- 每行对应一项任务：左侧显示任务名称和负责人，右侧显示任务条。
- 任务条按状态着色：未开始青色、进行中蓝色、已暂停紫色、已完成绿色、已取消灰色。
- 点击任务条复用现有任务详情抽屉；首版不在甘特图内变更任务。
- 没有进行中项目或时间窗内没有任务时，分别显示明确的空状态。

## 实现边界

- 首版只展示任务计划日期，不以实际开始/结束时间替代排期。
- 不增加后端 API。前端在选中项目后分页获取该项目任务，并对窗口交集做筛选；实现时需要保证能取到窗口内全部任务，不能仅取默认第一页。
- 任务详情继续使用现有权限和数据请求链路。

## 验收标准

1. Dashboard 可以选择任一进行中项目。
2. 甘特图稳定显示连续 14 天，今天位置正确。
3. 项目任务在日期窗口中的起止位置正确，跨边界任务不溢出。
4. 五种任务状态颜色正确，点击任务能打开详情。
5. 两种空状态可区分，窄屏下可横向滚动且不挤压任务信息。
